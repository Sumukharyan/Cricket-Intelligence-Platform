# Smart Cricket Shot Analytics System

## Project Overview

The Smart Cricket Shot Analytics System is a sports analytics platform that combines Electronics and Communication Engineering (ECE), Computer Vision, Machine Learning, and Cricket Performance Analysis.

The system captures batting movements using an MPU6050 sensor mounted on a cricket bat and video recordings processed using MediaPipe. Sensor and vision data are fused to classify cricket shots and generate performance metrics such as Timing Score, Power Score, Balance Score, and Shot Quality Score.

---

## Objectives

- Classify cricket shots using sensor and vision data
- Analyze batting biomechanics
- Generate performance metrics
- Build a sports analytics dashboard
- Demonstrate integration of ECE and Sports Analytics
